# Diagramas del periférico `perip_i2s`

Cada diagrama se guarda en `.png` y en `.pdf`. Los nombres de bloques, señales, estados y parámetros deben coincidir con los del Verilog.

| Archivo | Contenido | Estado |
|---|---|---|
| `i2s_flujo` | Diagrama de flujo del transmisor | Borrador (`i2s_flujo.png`) |
| `i2s_bloques` | `perip_i2s` y sus submódulos: CSR, `fifo_i2s`, `div_i2s`, `slot_i2s`, `shr_i2s`, `ctrl_i2s` | Pendiente |
| `i2s_estados` | FSM `ctrl_i2s`: `IDLE`, `LOAD`, `LOW`, `HIGH`, `SHIFT` | Pendiente |
